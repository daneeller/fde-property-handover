> 说明：本套资料基于**合成训练场景**，访谈与数据均为模拟，不代表真实授权、业务执行或客户验收。

## 一、作业简介

围绕「交房缺陷与整改协同」场景，访谈六类角色（交付总经理、现场验房员、整改项目专员、交付平台工程师、工程质量经理、客户关系主管），
完成现场调研、现状流程还原、四来源收敛（Buyer / Operator / Brief / Industry）与需求假设整理。

## 四、关键结论（摘要）

1. 优先验证「照片—户型部位—返工位置」缺陷定位辅助，直接对应重复缺陷占比与分派核对耗时。
2. 「未复验关单」需设强制人工兜底卡点，是明确的验收红线。
3. 复验通过率统计口径须先统一（一缺陷多工单导致重复计数）。
4. 「完成」定义需跨岗统一（施工＝整改结束，客户＝复验通过）。
5. 权限与审批边界需先形成矩阵，AI 建议仅限只读提示，不触发状态变更。
